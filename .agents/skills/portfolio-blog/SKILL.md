# Portfolio blog

Read `content/README.md`, `docs/AUTHORING.md`, and `design/components/blog.md`. Blog landing copy belongs in `content/blog/{locale}/_index.mdx`; project mother documents use `content/blog/{locale}/projects/{project-id}/overview.mdx`, and child articles sit beside them. Put new factual AI-authored articles in `content/blog/{locale}/...` with `draft: true` unless the user explicitly approves publication. Use supplied evidence only, preserve translation IDs, derive parent projects from folders, validate links and build output, and report missing citations or translations.
