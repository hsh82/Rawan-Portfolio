# Portfolio blog

Read `content/README.md`, `docs/AUTHORING.md`, and `design/components/blog.md`. Blog landing copy belongs in `content/blog/landing/{entry.json,en.mdx,fa.mdx}`. Each project hub uses `content/blog/projects/{project-id}/{entry.json,en.mdx,fa.mdx}` and child articles use `articles/{slug}/{entry.json,en.mdx,fa.mdx}`. Put new factual AI-authored articles in the unified entity layout with `status: "draft"` unless the user explicitly approves publication. Use supplied evidence only, preserve translation IDs, derive parent projects from folders, validate links and build output, and report missing citations or translations.
