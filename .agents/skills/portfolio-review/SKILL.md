# Portfolio review

Read `AGENTS.md`. Run `npm run content:validate`, `npm run content:check-links`, `npm run check`, `npm run build`, and `npm run test:static`. Inspect failures, missing translations, duplicate IDs, invalid dates, drafts, links, and résumé configuration. Never make factual content up to resolve an error.
