# Portfolio review

Read `AGENTS.md`. Run `npm run content:validate`, `npm run content:check-links`, `npm run test:content-api`, `npm run check`, `npm run build`, and `npm run test:static`. Inspect failures, missing translations, duplicate IDs, invalid dates, drafts, parent-project relationships, favorite dates, links, and résumé configuration. Never make factual content up to resolve an error.
