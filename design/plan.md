# Portfolio platform plan

The site is an Astro static bilingual portfolio with two top-level areas per locale: the single-page portfolio at `/{locale}/` and the blog at `/{locale}/blog/`. Blog category archives and article routes nest under the blog. Application code lives in `src/`; all owner-specific public data lives in `content/`. English and Persian share component trees and use locale routes with `dir` metadata. Blog MDX is loaded from `content/blog`; structured JSON feeds homepage Journey, project, contact, and résumé views.

The homepage reads profile, experience, skills, projects, journey, contact, and résumé configuration from structured JSON. A clean checkout may contain empty owner content and renders intentional empty states until the maintainer adds verified records. The homepage progress navigator tracks homepage sections only; résumé access is a generated header PDF button when enabled. Localized Journey, Projects, Contact, and Résumé pages remain available without requiring personal data. Project articles are nested under the blog and linked by stable project IDs. Static build, content validation, link validation, résumé generation, and route checks are the baseline.
