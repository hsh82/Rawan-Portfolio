# نگارش محلی در مرحلهٔ آزمایشی

با `npm run dev:content` یا `npm run preview:content` شروع کنید و مسیر `/dev/content/` را باز کنید. هر دو دستور برای نگارش محلی از روی منبع هستند. دستور عادی `npm run preview` فقط `dist/` را می‌خواند. خروجی استاتیک سایت، مسیر و API نوشتنِ ویرایشگر ندارد.

بخش‌های تجربه، تحصیلات، گواهی‌ها، مهارت‌ها و مسیر حرفه‌ای هر کدام یک ویرایشگر برای آرایهٔ کامل فایل JSON دارند. رکوردها را مستقیم در همان آرایه اضافه، ویرایش یا حذف کنید و سپس «ذخیرهٔ تغییرات» را بزنید. دکمه و مرحلهٔ جداگانه‌ای برای ساخت، انتخاب یا ورود رکورد وجود ندارد.

اگر فایل خالی باشد، نمونهٔ مخفی و دوزبانه داخل خود JSON نمایش داده می‌شود و تا ذخیره چیزی در فایل اصلی نوشته نمی‌شود. فقط اطلاعات تأییدشده بنویسید و شناسه‌های موجود را حفظ کنید. اعتبارسنجی نوع داده، شناسهٔ تکراری و پیوندهای رزومه و پروژه پیش از ذخیره انجام می‌شود. خطای 409 یعنی فایل بیرون از ویرایشگر تغییر کرده است.

فاصله و BOM، حصار Markdown با برچسب JSON، ویرگول انتهایی و خط جدیدِ بدون escape در رشته، در موارد بی‌ابهام قابل اصلاح هستند. «قالب‌بندی / اصلاح JSON» تغییرات نحوی را پیش از اعمال نشان می‌دهد. نام فیلد تکراری، ساختار مبهم، نوع نادرست و شناسهٔ ناسازگار رد می‌شوند. مقدارها، روابط، وضعیت انتشار و اطلاعات واقعی حدس زده نمی‌شوند. پیام خطا مسیر دقیق فیلد را نشان می‌دهد؛ ذخیرهٔ نامعتبر فایل اصلی را تغییر نمی‌دهد.

ویرایش معتبر پس از حدود ۴۰۰ میلی‌ثانیه به پیش‌نمایش واقعی صفحهٔ اصلی می‌رود، بدون ذخیرهٔ فایل. برای JSON موقتاً نامعتبر، آخرین نمای معتبر با هشدار قدیمی‌بودن حفظ می‌شود. جدیدترین تغییر بر پاسخ قدیمی اولویت دارد. نشست‌ها محلی، موقت و محدود هستند؛ اسکریپت و ارسال فرم در پیش‌نمایش اجرا نمی‌شود.

نمای دسکتاپ با عرض ۱۲۸۰ و موبایل با عرض ۳۹۰ پیکسل است. «بزرگ‌کردن پیش‌نمایش» فضای صفحه را در اختیار پیش‌نمایش می‌گذارد؛ دکمهٔ خروج و کلید Escape آن را می‌بندند. تغییر اندازه، زبان یا بزرگ‌نمایی، متن ذخیره‌نشده را از بین نمی‌برد.

«دستیار نگارش» در نوار بالا یک پنجرهٔ قابل استفاده با صفحه‌کلید باز می‌کند. پرامپتِ دارای ساختار و زمینهٔ فعلی را در دستیار دلخواه خود کپی کنید. روند، بخش‌به‌بخش است: توضیح، مرور اطلاعات موجود، پرسش ضروری، پیش‌نویس انگلیسی و فارسی، JSON و محل دقیق قرارگیری، سپس تأیید یا رد همان بخش. سرویس AI یا کلید API لازم نیست و این پنجره به‌جای شما ذخیره نمی‌کند.

«عملیات بیشتر» اعتبارسنجی، اصلاح JSON و تغییرات Git را گروه‌بندی می‌کند. وبلاگ و پروژه ویرایشگر MDX دوزبانهٔ خود را حفظ کرده‌اند: ذخیرهٔ پیش‌نویس، انتشار و لغو انتشار عملیات جداگانه هستند. برای پروژهٔ موجود، «پیش‌نمایش صفحهٔ اصلی» کارت ذخیره‌نشده را با وضعیت انتشار فعلی نشان می‌دهد؛ پروژهٔ پیش‌نویس خودکار عمومی نمی‌شود. کد اجرایی MDX در پیش‌نمایش بصری اجرا نمی‌شود و متن پیشرفته در Source باقی می‌ماند.

برای بازبینی، اعتبارسنجی محتوا و لینک‌ها، `npm run check`، `npm run build`، `npm test`، `npm run test:studio` و `npm run test:studio-ui` را اجرا کنید. آزمون مرورگر به Chrome نصب‌شده یا `CHROME_BIN` نیاز دارد و داده‌های مصنوعی مستقل از مالک می‌سازد. نتیجهٔ واقعی هر سیستم‌عامل و محدودیت‌ها را در [گزارش نگارش](../design/reports/2026-11-09-easy-content-staging.md) ببینید.
